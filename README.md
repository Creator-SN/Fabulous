# Fabulous Desktop

Fabulous Desktop is the Electron edition of the Fabulous ecosystem.

It combines:

- local notebook editing with `.fbn`, Markdown, HTML, and JSON support
- document-centered note taking
- PDF reading and literature management workflows
- desktop file association, local folder browsing, and automatic updates

## Highlights

- WYSIWYG notebook editing with Markdown-friendly workflows
- Local-first notebook browsing and file operations
- `.fbn` desktop file association support
- Remote service integration for the broader Fabulous ecosystem
- Windows and macOS desktop builds
